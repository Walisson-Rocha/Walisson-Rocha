## 👋 Sobre mim

Sou o Walisson, desenvolvedor que gosta de resolver problemas de ponta a ponta — do banco de dados à interface. Já construí sistemas usados no dia a dia real de negócios: validação de certificados, PDV, gestão de clínica odontológica e emissão de notas fiscais. Hoje meu foco é o ecossistema JavaScript/React, com uma base sólida em C#.
